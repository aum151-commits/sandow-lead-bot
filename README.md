# Лид-бот «Сандов Фитнес»

Собирает контакт за подарок и отправляет заявку в группу «Sandow заявки».

| Что | Где |
|---|---|
| Адрес сервиса | https://sandow-lead-bot.onrender.com |
| Проверка живости | https://sandow-lead-bot.onrender.com/health |
| Работает на боте | @SandowMarketig_bot — на него уже ведёт сайт |
| Прежняя ссылка на сайте | @sandowfitness_ru_bot — чужой бот, заменён 11.08.2026 |
| Заявки падают в | группу «Sandow заявки» (`-1001793724014`) |
| Код | `bot.py`, деплой из github.com/aum151-commits/sandow-lead-bot |
| Render | сервис `srv-d9t3dhdbedkc73eiqpq0`, тариф free |

## Диалог

Три шага: цель → удобное время → номер. Подарок зависит от цели: для единоборств
это первая тренировка по боксу, для остальных — вводная тренировка с тренером и
экскурсия. Обещанный подарок уходит в заявку, чтобы менеджер знал, что подтверждать.

На частые вопросы (цена, бассейн, адрес, режим, сауна, тренеры) бот отвечает сам и
возвращает к заявке. Цены не называет — только разовое посещение 990 ₽.

Один человек — одна заявка в сутки, чтобы менеджеров не заваливало.

## Переехать на бота с красивым именем

Сейчас у бота отображается «Сандов Фитнес», но адрес — @SandowMarketig_bot, с
опечаткой в слове marketing. Если завести отдельного бота:

1. @BotFather → `/newbot` → имя «Сандов Фитнес», адрес `sandowclub_bot` или
   `sandowfit_bot` (на 11.08.2026 оба свободны). BotFather выдаст токен.
2. Подставить токен в переменную `TELEGRAM_BOT_TOKEN` сервиса на Render.
3. Заново поставить webhook:
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://sandow-lead-bot.onrender.com/tg/<HOOK_SECRET>`
4. Поменять ссылку на сайте:
   `python -m src.rpa.tilda_fix_tg_link --bot sandowclub_bot` из папки
   `yandex-business-automation` (скрипт правит виджет и футер, затем публикует).

`HOOK_SECRET` смотреть в переменных сервиса на Render.

## Выкатить изменения

Правки в `bot.py` → скопировать файл в клон репозитория → `git push`. Render
пересоберёт сам за пару минут (autoDeploy включён).

## Про бесплатный тариф

Render усыпляет сервис после 15 минут тишины, пробуждение около 40 секунд. Задача
планировщика «Сандов - бот лидов не спит» пингует его каждые 10 минут с 8:00 до
23:00 — но только когда ноутбук включён. Ночью бот спит намеренно: так хватает
750 бесплатных часов в месяц на два сервиса вместе с голосовым тренажёром.

Совсем убрать задержку можно внешним пингером (cron-job.org, UptimeRobot) —
нужна регистрация по почте.
